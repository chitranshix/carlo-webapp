# Carlo

Carlo is a small, focused tool for actually learning GRE vocabulary — not just staring at flashcards. Open it and you're immediately matched against five words, working out which definition belongs to which word, no setup required. Words you're still shaky on come back around; words you've nailed step aside. The full list of 1,069 words is always a click away for browsing, but browsing was never the point — testing yourself is. Carlo is built around one idea: you don't learn a word by seeing it, you learn it by being asked.
